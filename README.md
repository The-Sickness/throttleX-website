## 📱 About ThrottleX

ThrottleX transforms your Android phone into a professional grade motorcycle telemetry system — no expensive hardware required.

| | |
|---|---|
| **Platform** | Android |
| **Price** | $9.99 one-time purchase |
| **Trial** | 7-day free trial |
| **Subscriptions** | None. Ever. |
| **Ads** | None. Ever. |

**Core features:** Real-time lean angle, G-force, GPS speed, voice coaching, crash detection, ride history, and garage tracking.

## 🚀 Local Development

Since this is a static site, there is no build step. To run it locally:

```bash
git clone https://github.com/The-Sickness/throttleX-website.git
cd throttleX-website
```

Then open `index.html` in your browser, or use any static file server:

```bash
# Python
python3 -m http.server 8080

# Node (if you have npx)
npx serve .
```
